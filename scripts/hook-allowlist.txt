# Hook names check-hook-names.sh accepts without finding them in the WordPress source.
#
# One fnmatch pattern per line (`*` matches any text). The source lookup ignores
# definitions whose only dynamic part is trailing (do_action( "edit_{$taxonomy}" )),
# because they would vouch for every typo. List those families here, as narrowly as
# the family allows; never a whole namespace (`wp_*`, `admin_*`).
#
# Your own prefix (jp_permissions_) is always accepted and needs no entry. Add other
# prefixes you own (a companion plugin, a vendored library) as `acme_*` lines.
